# Proyecto Data Vocento

Documentación técnico-funcional consolidada del **Proyecto Data de Vocento** (proyecto DATAGORA),
generada a partir del análisis de la carpeta compartida
`PROYECTO DATA - CASOS DE USO` (1.451 archivos: actas, memorias técnicas, diccionarios de datos,
diagramas, código de Dataform/Dataplex, formaciones y documentación legal).

## Qué es este sitio
Un sitio de documentación **vivo**, navegable y con búsqueda, en el que los modelos de datos se
representan como **diagramas entidad-relación dinámicos (Mermaid)**.

## Cómo navegar
- **Visión general del proyecto** — resumen ejecutivo, seguimiento cronológico del programa y la
  Memoria Técnica oficial (Entregables E1-E23).
- **Espacio de Datos (EEDD)** — qué es, cómo funciona, cómo se gobierna, accesos y aspectos legales.
- **Gobierno del Dato y Calidad** — glosario de negocio, reglas de calidad, Dataplex y el modelo
  entidad-relación técnico (BigQuery/Dataform) por capas.
- **Publicidad / Clasificados / Suscripciones** — resumen funcional, arquitectura de datos y
  modelo entidad-relación de cada vertical de negocio.
- **Propuestas Comerciales, BI y Plan Data** — resto de iniciativas del plan de datos.
- **Formación y comunicación** — manual de usuario del EEDD, formaciones y notas de sesiones de
  gobernanza.
- **Anexos** — inventario documental completo y catálogo de grabaciones no transcritas.

!!! note "Alcance y limitaciones"
    Se ha revisado la práctica totalidad de documentos de texto (.docx, .xlsx, .pptx, .pdf) y
    código relevante (.sql, .sqlx, .drawio) del Drive. No se dispone de herramienta de
    transcripción de audio/vídeo: las 32 grabaciones `.mp4`/`.mkv` del proyecto se han catalogado
    como inventario (ver [Anexos > Grabaciones](anexos/grabaciones.md)) pero su contenido hablado
    no ha sido procesado; cuando existía documentación de texto asociada a esas sesiones, sí se ha
    incorporado a las secciones correspondientes.
